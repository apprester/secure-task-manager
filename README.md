# secure-task-manager
Secure web task-management platform with user accounts, projects, tasks and permissions with security designed into it from the beginning.

Technology
- Java + Spring Boot
- PostgreSQL and REST API
- Docker and automated tests

Security features
- Secure password hashing
- Authentication and role-based authorization
- Input validation and parameterized database queries
- Protection against common OWASP Top 10 vulnerabilities
- Secure configuration and secrets management
- Tests for unauthorized access and other security failures

Deliverables: Working application, architecture diagram, README, API documentation and security testing report.
